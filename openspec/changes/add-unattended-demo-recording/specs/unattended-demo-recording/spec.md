## ADDED Requirements

### Requirement: 一次双击启动无人值守录制
系统 SHALL 提供 Windows 双击入口，在不要求接收方安装 Node、录屏软件或 npm 依赖的前提下完成录制链路。

#### Scenario: 依赖齐全时开始录制
- **WHEN** 用户在最终便携包中双击录制入口，且随包 Node、FFmpeg、Edge、磁盘和显示条件均满足要求
- **THEN** 系统启动本地服务和浏览器、预热页面、开始自动演示并将 MP4 保存到带时间戳的录制目录

#### Scenario: 依赖缺失时安全停止
- **WHEN** Node、FFmpeg、Edge、磁盘或显示条件任一项不满足
- **THEN** 系统不得开始不完整录制，并在日志中给出具体缺失项和处理建议

### Requirement: 状态驱动的页面等待
分镜执行器 MUST 以可观察页面状态和网络空闲作为步骤成功条件，固定延迟只能作为状态达成后的展示停留。

#### Scenario: 接口响应较慢
- **WHEN** 点击后接口耗时超过常规值但仍在步骤超时内完成
- **THEN** 执行器等待网络空闲及目标状态出现后再进入下一分镜，并记录实际等待时间

#### Scenario: 页面状态未达成
- **WHEN** 目标元素或文本在步骤超时前始终未出现
- **THEN** 执行器停止后续点击、保存当前页面截图和步骤日志，并以失败状态结束录制

### Requirement: 可重复且与坐标无关的自动演示
分镜执行器 SHALL 通过语义定位器、稳定 ID 或 `data-*` 属性操作页面，不得依赖固定屏幕坐标。

#### Scenario: 页面布局有小幅调整
- **WHEN** 目标控件位置变化但语义定位器仍然存在
- **THEN** 执行器仍能将演示光标移动到控件中心并完成操作

### Requirement: 录制安全边界
自动演示 MUST 不输入凭证、不显示 UKey PIN、不点击申报或交易提交动作，并且失败时不得静默降级到危险操作。

#### Scenario: 分镜配置请求禁用动作
- **WHEN** 分镜包含提交申报、自动交易、凭证输入或未知高风险动作
- **THEN** 配置校验失败且录制不得开始

### Requirement: 可验收的 MP4 产物
录制完成后系统 SHALL 检查文件存在、容器、视频编码、分辨率、帧率、时长和文件大小。

#### Scenario: 产物符合比赛限制
- **WHEN** 输出为 H.264 MP4、1920×1080、30fps、时长小于五分钟且小于 200MB
- **THEN** 检查结果写入录制报告并返回成功

#### Scenario: 产物超限或损坏
- **WHEN** 输出缺失、不可探测、时长达到五分钟或文件达到 200MB
- **THEN** 检查返回失败并明确列出不合格指标
