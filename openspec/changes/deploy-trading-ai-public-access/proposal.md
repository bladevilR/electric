## Why

电力交易策略助手目前仅监听本机回环地址，只适合单机访问，无法通过内网应用服务器和 DMZ 代理形成可供外网用户访问的受控入口。现在需要把当前工作区版本定向部署到 `10.97.47.88`，并经 `172.16.20.233` 转发，同时保留明确的回滚路径和真实公网验收证据。

## What Changes

- 让 Node 服务支持通过环境变量配置监听地址，同时保持本地默认值 `127.0.0.1` 不变。
- 增加面向 `10.97.47.88` 的可重复部署单元、健康检查和服务保活配置。
- 在 `172.16.20.233` 上增加到应用服务器的反向代理入口，复用目标机已有 Web 服务和公网绑定，不擅自更换既有站点。
- 部署前记录现有端口、服务与代理配置，部署后提供原子回滚步骤。
- 从最终外网链接验证首页、健康接口和核心工作台页面，并保存截图与命令证据。

## Capabilities

### New Capabilities

- `public-web-deployment`: 规定应用监听、Linux 服务部署、DMZ 反向代理、健康检查、回滚及公网验收的行为要求。

### Modified Capabilities

无。

## Impact

- 代码：`trading-ai-system/server.mjs`、服务契约测试及部署相关配置/文档。
- 目标系统：Linux 应用服务器 `10.97.47.88`、Windows DMZ 代理 `172.16.20.233`、OSMS H5/SFTP 运维入口。
- 网络：应用内网监听端口、DMZ 到应用服务器的访问路径、DMZ 现有公网 Web 绑定。
- 安全：不改变 `human_decision_only` 执行边界；不提交或展示 Cookie、口令、UKey PIN、API Key 等敏感值。
