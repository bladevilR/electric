## Context

上一版参赛片以 Playwright 页面视频为素材，同时在浏览器内对 `#workbenchRoot` 做 1.0–1.9 倍 DOM 变换。该变换会影响后续元素坐标和滚动计算，曾在节约金额镜头附近生成空白构图。后续桌面级 FFmpeg 录制虽然绕开 DOM 变换，却录入终端、壁纸、白屏和窗口边缘，且没有旁白。用户要求整个制作过程由 Codex 全自动完成，成片严格少于 5 分钟。

## Goals / Non-Goals

**Goals:**

- 一条命令从本地演示入口生成可直接审片的最终 MP4。
- 浏览器只负责真实页面操作和干净素材采集；摄影机完全在后期执行。
- 按场景采集素材和焦点坐标，单场景失败可重录且不会污染其它镜头。
- 以 Serena 连续章节旁白的真实时长驱动画面、字幕和镜头节拍。
- 最终为 1920×1080、30fps、H.264/AAC，目标 220–250 秒，硬上限 300 秒。
- 自动检测桌面污染、黑白屏、冻结、静音、字幕越界和焦点裁切，并生成中文验收报告。

**Non-Goals:**

- 不依赖用户操作 Screen Studio、OpenScreen、OBS 或任意 GUI 编辑器。
- 不录制 macOS 桌面、浏览器地址栏、菜单栏、Dock 或其它应用。
- 不触发真实申报，不把演示规模测算写成生产收益承诺。
- 不重做交易业务功能和前端视觉系统。

## Decisions

1. **页面级高分辨率素材。** Playwright 录制时让实际视口与视频画布同为 3840×2160，并注入仅录制态使用的固定 1920×1080 舞台缩放。先跑 10 秒 smoke；若媒体尺寸、画布占用或关键文字清晰度不合格，则终止正式制作，不回退到桌面录制。
2. **分场景而非一镜到底。** 每个场景从确定的 URL/状态开始，等待可观察 DOM 条件，执行一次真实操作并记录目标矩形。片头、片尾和 12–15 个业务场景分别输出素材；失败只重录该场景。
3. **页面不执行摄影机变换。** 录制器保留字幕、演示标识、光标和点击波纹，但禁止 `#workbenchRoot` 缩放。镜头时间线使用源素材坐标生成 1.0 全景、1.25–1.4 中景、1.5–1.75 特写和最多 1.85 的英雄特写。
4. **程序化后期摄影机。** 使用 Node 生成确定性的 FFmpeg filter graph，对 4K 素材做逐帧 crop/scale/concat；字幕和标识在缩放后叠加，避免跟随画面变形。镜头采用 `cubic-bezier(.16,1,.3,1)` 等价缓动，不旋转、不弹跳。
5. **旁白优先。** 复用并重新验证四章 Qwen3-TTS Serena 音频；模型、speaker、seed、instruct 固定。真实音频时长决定场景持续时间，非设计静音不得超过 1.5 秒。
6. **价值优先叙事。** 前 15 秒出现单日 2.4 万、月度 52.8 万、年度 633.6 万的演示测算；随后按数据门禁、预测、96 点申报优化、成本证据、人工复核、结算回流和候选策略验证展开。年度金额只出现一次。
7. **双层验收。** 机器门禁负责媒体、时长、画面异常、声音和时间线；Codex 再检查密集抽帧、关键连续帧并完整播放最终 MP4。任一失败都定位到场景后重录或重渲染。

## Risks / Trade-offs

- **4K Playwright 视频仍可能出现灰区或布局变化** → 实际视口与录制尺寸必须相同；录制前执行 10 秒 smoke 和四角像素/目标矩形检查。
- **FFmpeg 动态 crop 表达式复杂** → 摄影机先转换为逐帧可测试参数，再生成 filter graph；单元测试覆盖边界和缓动。
- **分场景切换可能显得跳跃** → 仅在章节边界硬切，章内使用 8–14 帧交叉淡化或从相近构图衔接。
- **高倍率特写可能裁掉上下文** → 目标矩形加 12%–18% 安全边距，并限制 crop 在素材边界内。
- **旁白生成耗时** → 音频内容和参数未变时按 manifest 哈希复用；任何文案或参数变化必须重生成。

## Migration Plan

1. 为页面素材、摄影机时间线和验收规则补失败测试。
2. 实现无 DOM 摄影机的高分辨率 smoke，验证通过后才录正式素材。
3. 实现程序化后期摄影机与字幕/旁白合成。
4. 一键生成最终成片，执行自动检测、密集抽帧和完整播放验收。
5. 将通过验收的 MP4、时间线、探测信息、截图和报告复制回主项目；保留旧提交可回滚。
