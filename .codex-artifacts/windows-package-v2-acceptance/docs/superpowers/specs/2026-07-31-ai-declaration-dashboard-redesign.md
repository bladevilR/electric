# AI 申报优化比赛展示页设计规格

## 目标

将当前“电力交易智能决策平台”工作台重构为以 **AI 申报优化** 为唯一首屏主题的比赛展示页。页面应在 1920×1080 录屏中无需滚动即可回答四个问题：

1. 系统优化了什么；
2. 优化是否经过真实历史验证；
3. 当前建议能否进入人工复核；
4. 证据和风险边界在哪里。

目标视觉以 [ai-declaration-dashboard-target.png](../../design-reference/ai-declaration-dashboard-target.png) 为合同。实现必须保持真实 DOM、SVG 或 Canvas，不得将目标图直接作为页面背景。

## 设计边界

### 保留

- 当前本地服务、API、人工复核动作和审计模式。
- 四步业务闭环：数据接入、质量校验、策略决策、结算评估。
- 申报优化器的独立留出集结果、推荐覆盖、回退机制和“不自动提交”边界。
- 现有加载、空数据、错误、演示和审计状态。

### 重构

- 决策模式首屏的信息架构、页面布局、视觉令牌和图表表达。
- 现有占据固定宽度的证据侧栏改为按需展开，不再在关闭时保留空白列。
- 原有多个同权重卡片收敛为：主题区、四项证据、96 点主图、AI 建议、流程条。
- 辅助导航只链接真实页面区域或真实模式，不增加无功能按钮。

### 不做

- 不修改申报优化算法、晋级门槛或交易安全边界。
- 不自动提交交易，不绕过人工复核。
- 不把偏差改善解释为人民币节省。
- 不写死 `+9.64%`、`86.05%`、`4,128 点 / 43 日` 或 `92/100`。
- 不为匹配目标图伪造机组、成本、收益或执行状态。

## 页面结构

### 1. 左侧导航

宽度约 208px，包含品牌、当前主题和真实入口：

- AI 申报优化：回到首屏；
- 曲线对比：滚动或聚焦 96 点主图；
- 数据校验：切换到现有 `validate` 阶段；
- 模型验证：打开现有审计/验证内容；
- 审计证据：打开证据链；
- 操作指引：打开现有 `一分钟上手.html`。

窄桌面下收敛为图标轨道；不得出现点击后无响应的装饰菜单。

### 2. 主题区

- 一级标题：`AI申报优化`。
- 副标题根据推荐状态动态生成：
  - `ready`：已生成目标日复核建议；
  - `baseline_ready`：优化器未晋级，当前保留默认申报；
  - `missing_baseline`：目标日默认申报不完整；
  - `stale_inputs`：历史实际负荷已过期；
  - 其他状态：明确显示待补数据。
- 右上保留交易日选择器和三步状态：AI 生成建议、人工复核、提交申报。第三步只表达业务流程，不提供自动提交按钮。
- 可使用轻量流线装饰增强空间感，但不得承载文字或控件。

### 3. 四项证据

四项证据位于同一横向容器，数据均来自真实响应：

| 目标项 | 数据来源 | 缺失处理 |
|---|---|---|
| 偏差改善 | `strategyValidation.declarationOptimizer.holdout.improvementPct` | 显示“待验证” |
| 交易日胜率 | `strategyValidation.declarationOptimizer.holdout.dailyWinRatePct` | 显示“待验证” |
| 优化规模 | `holdout.pointCount` 与 `holdout.dateCount` | 显示实际可比点和日期 |
| 数据置信度 | `costStrategy.dataConfidence.score` | 未加载时显示“待校验”，禁止默认 92 |

状态色只表达语义：通过为绿色、待复核为琥珀色、阻塞或退化为红色/灰色。

### 4. 96 点申报曲线

主图是首屏最大区域。数据来自 `declarationRecommendation.rows`：

- 基线申报：`baselinePowerMw`；
- AI 建议申报：`recommendedPowerMw`；
- 差值：`deltaPowerMw`；
- 点位：`pointIndex` 与 `timePoint`；
- 回退点：`fallbackUsed`。

实现要求：

- 使用真实 SVG 绘制，不引入新的大型图表依赖；
- 96 点不足时按实际点数绘制，并明确覆盖率；
- 无建议行时显示可解释空状态，不绘制假曲线；
- 支持键盘聚焦或鼠标悬停查看点位、基线、建议和差值；
- 正差和负差使用不同语义色，回退点有明确标记；
- 不显示当前 API 未提供的“预计实际负荷”或虚构价格曲线。

### 5. AI 优化建议

右侧建议卡只展示可证实内容：

- 推荐状态；
- 偏差改善结果；
- 根据 `deltaPowerMw` 聚合得到的主要上调/下调时间窗；
- 推荐点、优化器点、回退点覆盖；
- 当前风险或回退原因；
- 主动作：沿用现有 `primaryAction` 和 `runPrimaryAction`。

当前 `costSavingsYuan` 为 `null` 时，不显示人民币节省金额。人工复核按钮不得直接提交交易。

### 6. 优化流程

底部流程条展示：

1. 数据准备；
2. AI 建模预测；
3. 生成优化建议；
4. 人工复核；
5. 提交申报。

前四步映射现有数据状态；第五步始终是外部人工业务动作，只显示“待提交”或“已记录”，不提供自动提交能力。

### 7. 审计模式

保留现有审计模式和成本优化证据链，但改为覆盖式抽屉或独立主区域。关闭时不得占据固定网格列。审计模式继续展示：

- 历史策略验证；
- 申报优化器留出集；
- 数据证据；
- 操作留痕；
- 成本公式与“结算后才计入实际节省”的边界。

## 视觉合同

### 色彩

- 页面环境：冷白到浅冰蓝；
- 主色：高纯度钴蓝；
- 已验证改善：青绿色；
- 模型/规模：紫色；
- 待人工复核：暖橙色；
- 正文：深海军蓝，不使用纯黑。

### 材质

| 表面 | 角色 | 工程实现 |
|---|---|---|
| `page-air` | 页面环境 | 多层低透明度径向渐变与轻微噪点 |
| `resin-panel` | 主图和建议卡 | 乳白实色、1px 冷蓝边、浅接触阴影 |
| `signal-chip` | 指标图标和状态 | 低透明度色晕、实体中心、无大面积模糊 |
| `energy-ribbon` | 主题装饰 | 独立伪元素或小型 SVG，不含文字 |
| `action-gradient` | 唯一主按钮 | 蓝到紫的短程渐变，仅用于主动作 |

不得把所有卡片做成透明玻璃；不得使用彩虹渐变、强发光、软塑料 3D 或背景图承载控件。

### 排版与密度

- 首屏一级标题 42–54px；
- 核心数据 30–42px；
- 正文不低于 13px；
- 录屏中需要阅读的说明不低于 14px；
- 通过减少内容而不是压缩字号适配 1080p。

## 状态设计

- `loading`：保留品牌和页面骨架，显示正在加载申报数据。
- `blocked`：主题保持不变，主图替换为数据缺口和唯一修复动作。
- `baseline_ready`：显示默认申报曲线，明确优化器未晋级。
- `ready`：显示基线与 AI 建议双曲线，可进入人工复核。
- `verified`：显示结算证据入口，不把演示金额当真实金额。
- `error`：隐藏本地绝对路径，只显示可执行错误摘要和重新加载按钮。
- `demo`：继续显著标注“演示状态”，不得与真实生产状态混淆。

## 响应式

- 目标视口：1920×1080；
- 窄桌面：1280×720，左栏缩为图标轨道，四指标允许两行；
- 低于 1100px：主图与建议卡改为上下布局；
- 保持键盘焦点、语义标题、按钮名称和足够对比度。

## 实现边界

- 主要修改 `workbench.js` 与 `workbench.css`。
- 可增加一个小型纯函数模块，用于构建首屏视图模型、点位窗口和 SVG 路径。
- 可扩展前端并行加载 `/api/cost-strategy` 以获取真实 `dataConfidence.score`。
- 不改变现有 API 合同，除非实现时发现无法避免；若需要新增字段，先补测试。
- 不引入第三方 UI 或图表依赖。

## 验收

### 自动验证

- 原有 Node 测试保持通过；外部数据缺失导致的既有失败单独记录。
- 增加首屏渲染测试，覆盖 `ready`、`baseline_ready`、`blocked`、无置信度和 HTML 转义。
- 增加 96 点 SVG/点位窗口纯函数测试。

### 真实浏览器验证

在 1920×1080 与 1280×720 检查：

- 首屏主题、四项证据、96 点曲线、建议卡和流程条无需滚动；
- 关闭证据链后不再保留空白列；
- 曲线悬停、人工复核、审计切换、日期切换可用；
- 加载、空数据、错误和演示状态没有布局崩坏；
- 与目标图同视口截图对照，优先校准构图、层级、色场和字号。

## 差异账本

| 目标效果 | 实际实现原则 | 原因 | 补偿 |
|---|---|---|---|
| `92/100` 决策可信度 | 使用真实 `dataConfidence.score`，可能不是 92 | 禁止写死演示数字 | 保留相同视觉组件，缺失时显示“待校验” |
| 目标图中的成本金额 | 默认不显示 | 当前优化器明确返回 `costSavingsYuan: null` | 显示偏差改善和“结算后核算” |
| 目标图中的“预计实际”曲线 | 不绘制，除非 API 提供 | 当前推荐 API 不提供该序列 | 绘制基线、AI 建议和差值带 |
| 目标图中的完整提交步骤 | 仅显示业务流程 | 系统不会自动提交申报 | 人工复核后提示前往交易平台确认 |
