# 电力交易 AI · 两分钟本地模拟演示视频设计

## 目标

基于仓库最新前端与本地样本数据，制作一支约两分钟的比赛精华演示视频。成片必须在没有 UKey 的 macOS 环境独立完成，使用明确标注的演示状态，不把 mock 数据冒充生产结果。

## 成片结构

### 0:00–0:08 · 开场

- 项目名称：电力交易 AI · 智能申报决策
- 一句话价值：把数据校验、AI 申报优化、人工复核和审计证据整合为可追溯闭环
- 使用最新版浅色科技界面作为视觉主体，不额外制作脱离产品的概念 UI

### 0:08–1:42 · 核心演示

依次展示：

1. AI 申报优化总览
2. 偏差改善、交易日胜率、优化规模和决策可信度
3. 96 点历史申报与 AI 建议曲线
4. 关键调整窗口与可解释建议
5. 人工在环和“不会自动提交”的安全边界
6. 数据与计算证据链
7. 执行前质量门禁
8. 管理复核与审计模式

页面操作使用真实浏览器自动化。每个镜头等待目标元素可见和网络空闲后再停留，不使用绝对鼠标坐标或固定加载假设。

### 1:42–2:00 · 总结

- 回到 AI 申报优化首屏
- 总结数据、模型、建议、复核和审计闭环
- 强调系统是决策支持工具，未经人工复核不会提交申报

## 数据与真实性

- 浏览器地址使用 `/?demo=reviewable`，界面保留演示状态标识。
- 本地标准样本与演示场景只用于展示产品能力，不宣称为实时生产数据。
- 不输入、复制或伪造 UKey PIN、Cookie、证书、账号或交易凭证。
- 不点击申报提交、自动交易或其他不可逆动作。
- 指标仍由系统演示载荷驱动，不在视频后期覆盖成另一组数字。

## 录制与后期

- 使用 Playwright 驱动最新版真实页面并录制浏览器画面。
- 画布：1920×1080；帧率：30fps。
- 页面内显示平滑演示光标、点击波纹和短章节提示。
- 使用 macOS 中文 TTS 声线 `Tingting`，语速以自然且能在镜头停留内讲完为准。
- 解说按实际录制时间线分段合成；页面加载变慢时，字幕和音频随真实镜头顺延。
- 中文字幕烧录进视频，避免播放器不加载外挂字幕。
- 不添加背景音乐，优先保证旁白、字幕和界面信息清楚。

## 输出

- 主成片：MP4
- 视频：H.264、1920×1080、30fps、`yuv420p`
- 音频：AAC、48kHz、160kbps
- 目标时长：1分50秒至2分05秒
- 硬上限：2分10秒
- 文件大小：小于200MB
- 同时保留原始浏览器录屏、TTS分段音频、实际时间线和字幕文件，便于局部返工。

## 失败处理

- 页面目标元素超时：停止该次录制，保存截图和步骤日志，不继续盲点。
- TTS 超出镜头：优先压缩解说文字，其次小幅提高语速，不机械截断语音。
- 字幕遮挡关键指标：调整到画面底部安全区并增加半透明底板。
- 最终时长或体积超限：重新编码或收紧镜头停留，不删除安全边界说明。

## 验收标准

1. 真实浏览器完整跑通规定演示路径，无控制台错误或加载失败画面。
2. 开头、核心演示和结尾均存在，镜头顺序与设计一致。
3. TTS 可听清，无明显截断、重叠或长时间空白。
4. 字幕与语音同步，不遮挡核心指标和按钮。
5. 连续抽查至少五个时间点，画面不是重复帧、黑屏或被其他窗口遮挡。
6. 成片为 H.264/AAC MP4、1920×1080、30fps，时长不超过2分10秒、文件小于200MB。
7. 演示状态标识可见，不把本地 mock 冒充真实生产运行。
