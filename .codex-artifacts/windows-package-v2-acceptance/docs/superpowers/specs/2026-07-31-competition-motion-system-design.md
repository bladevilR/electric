# AI 申报优化比赛动效系统设计

## 目标

在不改变业务结构、数据含义和人工复核边界的前提下，为 AI 申报优化仪表盘增加一套适合比赛录屏的高级动效。动效必须强化“AI 已完成分析并给出可复核建议”这一主线，不得让装饰抢过指标、曲线和主动作。

## 设计选择

采用“比赛演示型动效”，拒绝持续闪烁的数据驾驶舱和强制自动滚屏导览。

```text
seed = len("你在用插件多做点酷炫动效") = 12
hero = Artistic Asymmetry；font = Geist-compatible system stack
components = metric choreography / evidence focus / progress rail；motion = timeline reveal / curve draw
```

本项目是单屏业务仪表盘，不照搬营销落地页的长滚动 AIDA。对应关系为：现有导航承担 Navigation，主题区承担 Attention，四项指标承担 Interest，96 点曲线与 AI 建议承担 Desire，人工复核按钮承担 Action。

## 动效编排

### 1. 首屏入场（0–1.8 秒）

- 侧栏先以短距离位移和透明度进入，不从屏幕外长距离飞入。
- 主题标题、说明和右侧三步流程按 80–120ms 间隔出现。
- 四项指标从左到右依次进入，数字由 0 滚动到真实展示值。
- 主图和 AI 建议最后进入，确保视觉注意力先建立主题，再落到证据。

### 2. 曲线生成（0.8–2.4 秒）

- 历史申报曲线先描边生成，AI 建议曲线延后约 180ms 追随生成。
- 面积层由低透明度渐显，不做大面积强发光。
- 13 个可见锚点沿曲线依次弹入；其余 96 个交互点继续保留但不常驻显示。
- 动效结束后保留轻微的曲线呼吸，不改变坐标或数据读数。

### 3. AI 建议聚焦（1.4–2.6 秒）

- 建议卡出现一次柔和的窄幅高光扫过。
- `+9.64%` 等真实指标做轻微上浮与清晰度增强。
- 主要调整窗口的条形从 0 扩展到实际宽度。
- “进入人工复核”按钮只做一次能量边缘流动，之后回到稳定状态。

### 4. 流程推进（2.0–3.0 秒）

- 数据准备、AI 建模预测、生成优化建议依次点亮。
- 人工复核节点停留在当前态，提交申报保持待提交态。
- 连线只做单次能量脉冲，不制造“系统已自动提交”的错误暗示。

### 5. 交互动效

- 指标卡悬停：轻微上移、边缘高光和图标位移，最大位移不超过 4px。
- 曲线点悬停/键盘聚焦：保持当前可读信息并放大目标锚点。
- 主按钮悬停：高光沿按钮方向移动，按下时有明确压感。
- 审计抽屉：使用短距离滑入与背景遮罩渐变，关闭时恢复焦点。

## 技术方案

- 使用本地 vendored GSAP core，保存到 `vendor/`，运行时不访问 CDN，确保同事的 Windows 电脑离线可用。
- 新增独立 `workbench-motion.js`，只负责查找已渲染 DOM 并创建/销毁时间线，不把动效状态混入业务数据。
- `renderBrowser()` 每次更新 DOM 后调用幂等的动效入口；重复渲染前先清理上一条时间线，避免叠加、内存泄漏或重复计数。
- CSS 提供初始态、材质高光、交互态和无 JavaScript 时的稳定终态。
- `prefers-reduced-motion: reduce` 下跳过时间线、数字滚动和持续呼吸，直接呈现最终状态。

## 视觉与性能边界

- 每个区域只允许一个主运动方向；禁止同时缩放、旋转、闪烁和位移。
- 不使用全屏粒子、鼠标拖尾、频繁浮动卡片、无限跑马灯或影响读数的视差。
- 动画优先只改 `transform`、`opacity`、`stroke-dashoffset` 和 CSS 变量。
- 首屏时间线不超过 3 秒；持续动效最多两处且振幅极低。
- 动画失败或 GSAP 未加载时必须回到完整静态页面，不能隐藏内容或按钮。

## 测试与验收

### 自动测试

1. 页面包含本地 GSAP 与 `workbench-motion.js`，不依赖远程 URL。
2. 动效模块能识别 `prefers-reduced-motion` 并直接进入终态。
3. 重复调用动效入口不会叠加时间线。
4. 数字滚动使用 DOM 中的真实值，不写死指标。
5. 现有工作台、曲线和安全边界测试全部保持通过。

### 真实浏览器验收

1. 在用户当前 2048×998 Chrome 与比赛目标 1920×1080 下完整播放一次首屏时间线。
2. 标题、四指标、96 点曲线、AI 建议和流程条顺序清楚，3 秒内稳定。
3. 曲线宽度继续覆盖主画布约 90% 以上，动效不得恢复此前居中缩窄问题。
4. 人工复核、审计切换、曲线悬停和导航仍可操作。
5. 页面控制台无错误；连续刷新三次无动画叠加。
6. 关闭动态效果后页面内容完整、无遮挡、无透明残留。

## 不做

- 不自动滚动页面，不替用户点击人工复核。
- 不修改优化算法、指标数值或数据来源。
- 不增加虚假收益、自动交易或提交成功动效。
- 不依赖比赛现场网络、浏览器扩展或操作系统特效。
