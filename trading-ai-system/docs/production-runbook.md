# 生产交易系统运行手册

## 当前边界

系统是本地电力交易辅助决策工作台，执行模式固定为 `human_decision_only`。它可以采集授权页面中可见的历史数据、生成价格预测与策略依据、复盘预测准确度，但不会绕过 CA/UKey、读取或保存 Cookie、Token、密码、证书私钥或 UKey PIN，也不会自动提交申报或交易。

## 启动

```powershell
.\run-system.ps1
```

默认地址为 `http://127.0.0.1:5177/`。进入左侧“基础数据”，页面顶部的“专用 Chrome”“UKey”“历史覆盖”和“全量回补”会显示采集系统的真实状态。

规范化证据默认保存在：

```text
%LOCALAPPDATA%\ElectricTradingAI\data\trading-evidence.sqlite
```

SQLite 是正式事实库；JSON 只用于兼容导入，CSV/JSON 只用于导出。

## 首次登录和全量回补

1. 插好 UKey，启动本地服务。
2. 在“基础数据”页点击“打开专用 Chrome”。系统会启动独立 Chrome 窗口并使用固定本地配置目录；采集期间不要关闭该窗口。
3. 在专用窗口中手工完成 JSPEC 登录和 UKey 确认。系统只观察登录后页面中可见的业务表格。
4. 页面状态由“等待登录”变为“已就绪”后，点击“开始全量回补”。
5. 系统按数据源、月份和业务日期逐日慢采，每个成功日期立即写入 SQLite 并更新断点；重复启动不会重复写入同一修订的数据。
6. 可随时点击“暂停”，再次点击“继续”会从最后成功日期恢复；服务重启后也会保留任务和游标。

不要把“任务已创建”当作“历史已采完”。只有状态为“已完成”，且完成分片数等于总分片数，才代表本次任务结束。

## 温度预报的正确口径

温度驱动来自 Open-Meteo：

- 模型输入使用目标时点前 24 小时可获得的历史天气预报（Previous Runs），避免把事后实况泄漏到预测中。
- 目标日结束后，才从历史天气接口回填实况温度，用于预测准确度复盘。
- 小时数据转换为 96 点并记录插值方法、坐标、提前量、来源和抓取时点。

默认位置为苏州市中心附近，可通过启动参数或环境配置更换经纬度。天气服务不可用时，页面会明确显示缺失，不使用模拟温度替代正式事实。

## 预测、复盘和历史查询

“基础数据与预测依据”页包含价格、温度、负荷三个页签：

- 曲线同时展示实况、P50 和 P10–P90 区间。
- “预测依据”列出来源、截止时点、样本量、模型版本和主要驱动。
- “策略形成”解释价格、温度和负荷如何组合为策略输入。
- “历史准确度”只统计不可变的 `live_issued` 预测与匹配实况，不把事后重新训练的结果混入现场准确度。
- “基础数据历史”支持按日期、字段和来源筛选，并可切换曲线、明细和采集证据。
- 页面底部微调区仅演示敏感性，不修改正式模型或策略。

具备至少 5 个完整价格历史日时可发布同点位基线预测；数据达到 30 个完整日并具备天气预报、负荷预报后，系统可使用透明的标准化岭回归驱动模型：

```text
预测价格 = 同点位历史基线 + β温度 × 温度偏差 + β负荷 × 负荷偏差
```

历史事实导出接口：

```text
GET /api/history/export?format=csv&from=YYYY-MM-DD&to=YYYY-MM-DD
GET /api/history/export?format=json&from=YYYY-MM-DD&to=YYYY-MM-DD
```

导出字段包含业务日期、点位、字段、数值、单位、来源、可用时点、采集时点和来源修订，不包含浏览器凭据。

## 异常恢复

- `login_required` / `login_expired`：回到专用 Chrome 手工登录，然后在工作台继续任务。
- `rate_limited`：不要反复点击。系统会停止当前节奏并按退避时间重试，最长等待 30 分钟。
- `page_changed` / `required_column_missing`：平台结构发生变化；保留采集证据并停止该数据源，修复适配器后从断点继续。
- `no_data`：记录该日期的空结果证据并继续下一日期，不伪造数据。
- 服务意外关闭：重新启动服务、打开专用 Chrome、完成登录，然后继续原任务。

## 安全停止条件

出现登录失效、访问频率警告、页面结构变更或无关页面时，系统必须暂停或拒绝本次采集，不得把失败页面写成成功数据。源返回空值会作为证据保存，不会用推测值补齐。

缺目标日实际负荷、结算、持仓或交易限额时，只能做预测误差复盘，不能声明真实节省金额，也不能预填可执行电量。
