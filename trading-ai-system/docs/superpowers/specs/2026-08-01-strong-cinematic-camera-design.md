# 强电影感产品演示运镜设计

## 目标

把当前“单次轻微放大”的参赛视频升级为肉眼明确可见的产品发布片镜头：以 4K 物理像素录制 1080p CSS 视口，一个章节内连续执行全景、中景、特写、横移和拉回，同时删除字幕中的“AI 解说”标签。

## 镜头尺度

- 全景：1.0–1.15，用于章节建立和拉回。
- 中景：1.30–1.45，用于单个功能区。
- 特写：1.60–1.75，用于曲线、公式、建议和策略卡。
- 英雄特写：最高 1.90，仅用于关键金额。
- 全片 16–20 个摄影机节拍，至少 6 个不低于 1.6；连续特写最多两个。

## 技术结构

Playwright 保持 1920×1080 CSS 视口，通过 CDP 设置 2 倍设备像素比并录制 3840×2160 原始视频。摄影机只变换 `#workbenchRoot`，字幕、章节和演示标识固定在 `body`。最终用 Lanczos 缩放到 1920×1080，从而保证高倍率特写清晰。

每个步骤的 `camera.beats` 按 0–1 时间比例描述多个焦点。动作使用 600–850ms，章节移动使用 1050–1400ms，相邻节拍直接连接，不加入旋转或弹跳。

## 固定分镜

- 金额：全景 → 三项测算 → 年度金额 → 拉回。
- 曲线：完整曲线 → 峰谷局部 → AI 建议。
- 证据：成本公式 → 成本明细 → 人工复核。
- 策略：现行策略 → 候选优化策略 → 历史回测与实时并行验证路径。

## 字幕

删除“AI 解说”标签和占位高度。只显示 36px 正文与关键词高亮，每屏最多两行，字幕不随摄影机缩放。

## 验收

4K smoke 必须由 ffprobe 证明为 3840×2160。最终视频必须低于 5 分钟、H.264/AAC 1080p，密集关键帧能够证明构图变化，无裁切、白屏、字幕遮挡或结尾金额重复。最后真实播放检查完整叙事与声音。
