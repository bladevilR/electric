# 现场字段探索补充：天气、机组供给与预测准确度

更新时间：2026-09-03  
关联主任务单：`trading-ai-system/docs/ukey现场字段探索任务单.md`  
关联字段字典：`trading-ai-system/docs/data-source-field-dictionary-v1.md`

## 1. 目的

主任务单继续负责 JSPEC P0-1～P0-8 与 P1-1～P1-3。本补充负责把天气、机组/供给、断面/跨区和预测准确度所需的来源与字段探索纳入同一验收口径。

当前电脑没有可用 JSPEC 页面，也没有已确认的生产气象接口。因此本文是现场执行清单，不代表字段已经真实可得。没有证据的项目必须写“待确认”，禁止根据监管文件、页面名称、接口猜测或演示数据填值。

## 2. 通用安全边界

- 只查看当前账号权限内可见页面、平台允许导出、公开资料或正式授权接口/文件。
- 不查看、截图、记录、复制 Cookie、Token、Authorization、UKey PIN、证书、私钥、密码、浏览器 Storage 或账号敏感信息。
- 不点击提交、确认申报、交易、保存、删除、撤回或任何可能改变业务状态的按钮。
- 不探测隐藏接口，不修改请求，不绕过权限，不自动申报或交易。
- 证据进入公开仓库前必须脱敏；真实明细默认保存在受控本地目录，仅在仓库保存字段结构、哈希、行数和不敏感证据索引。

## 4. W0 天气来源探索

### W0-1 生产主源：CMA/现有采购气象服务

必须确认：

- 正式产品名称、提供方和授权范围；
- 接口/文件是否允许业务生产使用、缓存、二次加工和内部展示；
- 是否提供历史“预报批次”，而不只是历史实况；
- `forecastIssuedAt`、`targetTime`、时区和预报时效；
- 站点/网格ID、经纬度、分辨率和覆盖苏州/江苏的方式；
- 温度、体感温度、露点、湿度、10米风、100米风、阵风、降水、降水概率、云量、短波辐射、天气现象等字段；
- 单位、原生时间粒度、更新频率、典型/最大延迟、历史深度和修订规则；
- 缺测、质量控制码和站点迁移/网格版本。

验收结果：生产主源必须能证明历史回测时使用的是当时已发布的预报版本。若只能取得当前预报或最终实况，状态为 `not_point_in_time_ready`，不得用于生产级历史回测。

### W0-2 开放预报补充源：ECMWF Open Data

必须确认实际实施配置：

- IFS/AIFS、确定性/集合、运行周期和 step；
- 下载入口或云镜像；
- 许可和归因要求；
- 目标网格和插值方式；
- 2米温度、2米露点、10米/100米风、总降水、总云量、短波辐射的具体参数和累计语义；
- 当前滚动档案保留时长；
- 自存任务是否成功保留每次运行的原始文件哈希、发布时间和下载时间。

验收结果：自存开始前的历史不能假装存在；需要完整历史时，必须使用合法档案服务或另一有历史批次的来源。

### W0-3 历史实际天气：CMA观测或ERA5/ERA5-Land

必须确认：

- 数据类别明确为 `observation` 或 `reanalysis`；
- 小时粒度、站点/网格、时区和更新时间；
- 实际天气字段、质量标记和缺测规则；
- 与天气预测字段的空间对齐方法。

验收结果：这些数据只作为实际结果、校准、缺测补全或气候常态；页面和数据库不得把它们标成历史预报。

### W0-4 交易96点对齐核验

选择一个完整日，逐项验证：

- 温度/湿度/风速的插值后96点首末值；
- 风向由U/V向量计算，不做角度算术平均；
- 一小时累计降水拆成4个15分钟后，四点之和等于原累计量；
- 辐射从J/m²转W/m²时使用正确累计区间秒数；
- `pointIndex=1`和`pointIndex=96`与交易页面时刻一致；
- 所有点仍保留原始批次、目标时刻、对齐方法和空间权重版本。

## 5. G0 机组、供给、断面与跨区探索

依据江苏2026年信息披露要求，优先寻找以下公开/授权页面，但具体可见性必须现场确认。

### G0-1 区域装机和发电量

确认：区域、机组类型、装机容量、发电量、统计周期、发布时间、单位、是否只有月度汇总。

用途边界：月度区域装机可以用于背景和长期特征，不能冒充逐点可用容量或单机状态。

### G0-2 发输变电检修计划

确认：资产/机组/场站/线路/变电设备标识、检修开始和结束、影响容量、计划发布时间、调整时间、状态和版本。

用途边界：原计划和调整计划必须追加版本；事后检修结果不能进入日前截止时点特征。

### G0-3 必开必停与开停约束

确认：机组稳定标识、必开/必停、总容量、所在位置、适用日期、最小开停约束名单、发布时间和更新规则。

用途边界：监管要求中的“名单及总容量”不等于页面一定提供单机额定容量、爬坡率或最小开停分钟数；未看到的参数保持待确认。

### G0-4 计划与实际出力

确认：日前计划、实时计划、计划调整、实际出力是否分别可见；单位、15分钟/小时粒度、发布时间、目标时刻和修订。

用途边界：当前代码/页面中的演示“186 MW、3/3在线、±18 MW”不能作为证据。

### G0-5 新能源预测和实际出力

确认：风电、光伏是否分开；区域/场站；预测发布时间、目标时刻、预测值、实际值、单位、粒度和历史深度。

用途边界：只有预测批次可进入日前模型；实际出力只用于实时特征或事后误差。

### G0-6 省间送受电和计划调整

确认：通道/方向、受入/外送、计划值、实际值、适用96点、原计划发布时间、调整发布时间和版本。

用途边界：正负方向和进口/出口约定必须写进字段目录，不能由数值符号猜测。

### G0-7 重要断面与过江通道

确认：断面稳定标识、96点潮流、正反向限额、预设约束、阻塞状态、发布时间、目标日、调整版本。

必须用至少一个正向和一个反向样例验证利用率公式。若页面只显示状态而不显示限额，不得反推限额。

### G0-8 节点价格分量

确认：节点/区域标识、总节点价、电能量分量、阻塞分量、单位、96点、发布时间、临时/最终状态。

核验：在允许误差内检查总价是否等于各分量之和；不成立时记录其他分量或口径差异，不强行修正。

### G0-9 市场调整事件

确认是否能读取：修改机组出力计划、外来/外送电、出清参数、预设约束、检修计划和既有出清结果的调整。

每个事件记录原值、新值、生效时刻、披露时刻、原因/类型和修订，不把事后事件回填到此前预测快照。

## 6. A0 预测与准确度现场验收

### A0-1 真实发布预测

选定一个目标交易日，在决策截止前生成预测并记录：

```text
forecastRunId
forecastGeneratedAt
decisionCutoffAt
targetTradingDate
pointIndex 1..96
目标价格口径
模型/特征/代码版本
训练日期范围
featureSnapshotId和hash
P10/P50/P90或点预测
输入完整度和降级原因
```

生成后不得覆盖。模型再次运行必须产生新`forecastRunId`。

### A0-2 临时/当前结果回填

临时日前价或实时当前价出现后，追加 outcome revision，记录来源发布时间、采集时间、来源修订和回填时间。不得写入最终价字段。

### A0-3 最终结果回填

最终价或最终结算出现后，再追加 final/settlement outcome。核验临时和最终记录同时存在，原预测未改变。

### A0-4 三种复盘隔离

页面分别验证：

- `真实发布预测`只统计现场真实保存的`live_issued`；
- `历史时点重放`只统计按历史cutoff重建的`point_in_time_replay`；
- `最终结算复盘`只在结算证据完整时计算经济指标。

三类样本数、日期范围、实际值版本和模型版本必须独立显示。

### A0-5 数据泄漏抽查

随机抽取至少3个预测运行和各3个点位，核对 feature snapshot 中每条输入：

```text
availableAt <= decisionCutoffAt
```

若有任一条违反，整次回测标记 `leakage_detected`，不得纳入模型晋级指标。

### A0-6 指标抽查

手工复算至少一个点预测样例、一个P10/P50/P90 pinball样例、一个区间覆盖样例、一个日级经济样例，确认页面和API一致。

## 7. 前端现场验收

### 数据源与质量

- P0/P1/天气/供给/预测审计来源均有状态、行数、非空点、日期覆盖、原生粒度、发布时间、采集时间、延迟和待办。
- 字段表完整显示用户要求的15列。
- `代码已支持`不能显示成`真实数据已就绪`。

### 市场驾驶舱

- 顶部显示目标交易日、as-of截止时点、市场阶段、真实/演示模式和数据完整度。
- 关键卡片的每个非空值均可打开证据抽屉。
- 天气/机组缺失时显示待确认或缺失，不显示演示值。

### 价格预测

- 明确目标是用户日前临时/最终、公开日前、实时当前/最终或实时加权均价中的哪一个。
- 同时展示强基线、Champion、Challenger、P10-P90和实际值；未校准区间明确标记。

### 申报策略

- 同时明确显示主动申报、缺省申报、用户日前出清电力、实际平均负荷/电量和推荐申报。
- 策略链完整显示数据、负荷、价格、供给/网络、持仓/限额、目标函数/约束、结果。
- MW与MWh限制分开展示。

### 历史复盘

- 三种复盘口径不混合；临时/最终实际值覆盖率分开。
- 无证据的指标显示“证据不足”，不显示0。

## 8. 回填完成定义

一个新增来源只有同时满足以下条件，才能从待确认升级：

```text
来源和授权确认
精确字段/表头确认
单位和粒度确认
发布时间/目标时刻/修订确认
两个日期或产品限制确认
脱敏样例和证据索引完成
机器可读field catalog更新
解析fixture和单元测试通过
真实模式页面正确显示来源和缺失状态
```

字段可见但无真实非空值时，只能升级为`confirmed_visible`或`captured_empty`，不能写`captured_nonempty`。
