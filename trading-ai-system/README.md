# 电力交易策略助手

这是一个本地运行的电力交易辅助工具。它把数据进度、结算参考、价格预测、预测验证、省钱策略和交易草稿复核放在一个工作台里，帮助你更快看清“现在能判断什么、还缺什么数据”。

## 一分钟上手

打开：

```text
一分钟上手.html
```

或者直接双击：

```text
启动系统.bat
```

启动后访问：

```text
http://127.0.0.1:5177/
```

## 日常使用

1. 插上 UKey。
2. 双击 `启动系统.bat`。
3. 在工作台先看“数据进度”“结算参考”“价格预测”“预测验证”。
4. 如需实时数据，进入“实时数据助手”，打开数据窗口并登录 JSPEC。
5. 点击“一键全量慢采”，系统会按完整清单后台慢采；你可以去做别的，但要保持 UKey、数据窗口和本地服务打开。
6. 回到“策略建议”查看低价窗口、高价风险和三档策略。
7. 生成报告或草稿后人工复核。

## 它能做什么

- 整理已有 raw captures 和本地 Excel 结算参考。
- 把价格、申报、负荷、结算等数据转成 96 点特征。
- 做价格预测基线和 walk-forward 验证。
- 给出省钱策略建议、置信度和数据缺口。
- 用一键全量慢采补齐 JSPEC 页面上可见的业务表格。
- 生成报告和交易草稿复核材料。

## 它不会做什么

- 不会读取 Cookie、Token、证书私钥或 UKey PIN。
- 不会绕过 CA/UKey 确认。
- 不会自动提交申报或交易。
- 在缺少目标日实际负荷、结算、持仓和交易限额时，不会输出可直接执行的电量。
