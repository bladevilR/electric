# 电力交易 AI 助手

这是本地试用版。它的用途很简单：帮用户把交易日数据、实时价格和 AI 建议放在一个页面里看清楚。

## 怎么启动

双击：

```text
start-ukey-assistant.bat
```

软件会自动打开浏览器。如果没有自动打开，手动访问：

```text
http://127.0.0.1:5177
```

模型地址、模型名和试用 Key 已经写在启动脚本里，不需要用户再配置。

## 怎么用实时数据

1. 进入页面左侧的“实时数据助手”。
2. 插上 UKey，点击“打开数据窗口”。
3. 在新打开的浏览器里登录交易平台，停在任意 JSPEC 页面即可。
4. 回到软件，点击“自动扫核心页”。系统会先巡扫首页、实时均价、实际负荷、日结算。
5. 看到巡扫行数后，可以点击“开始自动采集”持续观察当前页，或按需要低频补扫其他页面。

## AI策略页在做什么

“AI策略建议”页只做三件事：

- 看实时价格，找低价和高价观察窗口。
- 提醒哪些时段可能要重点复核。
- 把模型预测展示出来，供人工判断。

它不会自动下单，也不会自动提交申报。

## 草稿复核页在做什么

“交易草稿复核”页用于把当前建议整理成草稿，方便人工看一遍。草稿只是参考，最终仍然由用户在交易平台里确认。

## 重要边界

- UKey 登录只发生在用户自己的电脑上。
- 浏览器登录状态只保存在本机。
- 软件只读取页面上已经显示出来的业务表格。
- 软件不会替用户点击提交。
- 试用包里不包含本机浏览器登录目录。

## 每日省钱策略流程

1. 启动本地服务，打开 `http://127.0.0.1:5177`。
2. 打开 UKey 登录态浏览器，保持 JSPEC 页面可见。
3. 先看“数据资产”“结算参考”和“预测实验室”，确认当前 raw captures、Excel 参考文件、模型状态和缺口。
4. 只按“补采队列”慢速补采，默认最多 4 个目标，每个目标至少间隔 20 秒。
5. 查看“省钱策略”的保守、中性、激进三档建议；当前缺实际负荷、结算、持仓和限额时不会输出可执行电量。
6. 生成报告和交易草稿，人工复核后再决定是否在 JSPEC 手工操作。

## 当前预测边界

当前版本先做数据资产、结算参考、96 点特征、same-slot baseline、walk-forward 回测和人工决策支持，不直接训练深度学习模型。现在本地历史现货核对单已经能提供历史实际负荷和结算标签，交易计算表标准化 CSV 还能提供部分月末历史实际用电和申报功率；但目标日实际负荷、目标日结算、连续同日价格历史、持仓和交易限额仍需要补齐。没有这些目标日数据和业务约束，训练只会让系统看起来更复杂，却不能证明当天更省钱。后续补齐这些数据后，可以在同一套特征库和回测框架上升级到统计模型、树模型或神经网络模型。

本地 Excel 核对单、月度表和交易计算表标准化 CSV 已经通过“结算参考”登记进系统；历史核对单可转成历史 `actualKwh` / `settleAmount`，交易计算表 CSV 可补部分历史 `actualKwh` / `declarationPower`，但都不能替代目标交易日的实际负荷、结算和持仓约束。
