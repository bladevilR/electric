# 电力交易 AI 助手

这是本地试用版。它的用途很简单：帮用户把交易日数据、实时价格和 AI 建议放在一个页面里看清楚。

## 怎么启动

双击：

```text
start-ukey-assistant.bat
```

软件会自动打开浏览器。如果没有自动打开，手动访问：

```text
http://127.0.0.1:5177
```

模型地址、模型名和试用 Key 已经写在启动脚本里，不需要用户再配置。

## 怎么用实时数据

1. 进入页面左侧的“实时数据助手”。
2. 插上 UKey，点击“打开数据窗口”。
3. 在新打开的浏览器里手动登录交易平台，并打开实时价格或申报页面。
4. 回到软件，点击“采集一次”。
5. 看到采集行数后，可以点击“开始自动采集”。

## AI策略页在做什么

“AI策略建议”页只做三件事：

- 看实时价格，找低价和高价观察窗口。
- 提醒哪些时段可能要重点复核。
- 把模型预测展示出来，供人工判断。

它不会自动下单，也不会自动提交申报。

## 草稿复核页在做什么

“交易草稿复核”页用于把当前建议整理成草稿，方便人工看一遍。草稿只是参考，最终仍然由用户在交易平台里确认。

## 重要边界

- UKey 登录只发生在用户自己的电脑上。
- 浏览器登录状态只保存在本机。
- 软件只读取页面上已经显示出来的业务表格。
- 软件不会替用户点击提交。
- 试用包里不包含本机浏览器登录目录。
