# 电力交易 AI 系统 · 2026 年 9 月 4 日交付快照

## 启动

先把整个压缩包解压到普通文件夹，再双击「启动系统.bat」。Windows 10/11 64 位可用，已附带 Node.js 和 Playwright 依赖，不需要安装 Node.js。浏览器打开后先看「数据与预测」：默认是 2026 年 2 月 3 日，可切换月份、点击每一天，查看预测与实际对比及 96 个时段的误差。

主导航有数据与预测、市场概览、价格预测、申报策略、历史复盘、预测方法；「一分钟上手」为操作帮助。截图保存在「页面截图」文件夹。

## 如何理解结果

价格是主预测目标；温度、负荷是辅助依据。蓝色为预测，橙色为实际。月图按日均值比较，点选某天后看当天 96 点曲线和逐点差值。

「历史重算」是现在用该日期之前的历史数据重新计算，不代表当时已经发布过预测；「当时发布」才代表有发布时间记录的预测。缺少实际值时仍可显示预测，但不能计算真实准确度。温度历史实况为天气服务的再分析数据，不应等同于本地气象站观测。

## 数据范围与仍需补充的部分

包里带有打包时的真实数据快照，逐字段的起止日期、天数见「数据范围.json」。范围内可能有未覆盖日期，不代表起止日期之间每一天都有全部数据。本次为当前可运行版本交付，不是全量采集完结版；原机器的历史价格补采仍在继续，后续新增数据不会自动进入本压缩包。

近期真实用户负荷仍受到交易平台维护接口影响，部分持仓、交易限制、原始成交及供需资料尚未全部核验。页面保留这些提示，不把样例限制或缺失数据当作实盘依据。申报建议仅供复核，不会代替人工审核或自动提交交易。

## 继续采集

查看随包的历史数据无需平台登录。继续采集需本机安装 Chrome 或 Edge，并在系统启动的专用浏览器中由有权限的使用者登录平台，按需完成验证码/UKey 验证。包内不含账号密码、登录会话或原电脑的浏览器缓存；原采集任务以暂停状态随包保存，避免解压启动时直接请求平台。遇到维护、限频或验证时应等待或人工处理，不绕过平台限制。

Python 模型训练与 Excel 导入工具源码已附带；需要这些扩展功能时，需另行安装 Python 及对应 requirements。日常查看、历史查询、基础预测对比不依赖 Python。
